## Project description
Built a **Social Media Privacy Risk Assessment Framework** as a defensive cybersecurity project using Python, Flask, SQLite, HTML/CSS/JavaScript, and pytest.

The application uses a 40+ question privacy questionnaire to assess profile exposure, personal-information exposure, location privacy, content, connections, tagging, account security, third-party applications, social-engineering awareness, and digital footprint practices.

Key features include:
- Explainable 0–100 privacy-risk scoring
- Category-wise risk analysis
- Findings and personalized recommendations
- Privacy improvement simulator
- Privacy-safe analytics dashboard
- Synthetic 1,000-record dataset generator
- Printable assessment report
- Automated tests
- Privacy-by-design and data-minimization controls

The project is intentionally defensive: it does not scrape or track real social-media users, access private profiles, or collect unnecessary sensitive information.
