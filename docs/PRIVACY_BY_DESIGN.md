# Privacy by Design

- **Data minimization:** questions ask whether information is public rather than requesting the information itself.
- **Purpose limitation:** stored data supports risk analytics and findings only.
- **Least privilege:** third-party app recommendations follow least-privilege principles.
- **Privacy by default:** the demo uses synthetic/self-reported responses.
- **Transparency:** score, categories, findings, and assumptions are shown.
- **User control:** the assessment is voluntary and the simulator demonstrates changes without altering real accounts.
- **Retention limitation:** database schema contains assessment metadata, not raw answers or PII.
